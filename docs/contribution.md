# Процесс работы с репозиторием команды "Чемпионы"

## 📍 Ветки
- **main** — главная ветка, всегда стабильна
- **feature/название-задачи** — ветки для разработки
- **Примеры:** `feature/create-questionnaire`, `feature/add-protocol`

## 💬 Коммиты
Формат: `[тип] Описание`
- **feat:** новая функциональность
- **fix:** исправление
- **docs:** изменения в документации
- **style:** правки форматирования

## 🔄 Процесс внесения изменений
1. Создать ветку от `main`
2. Выполнить задачу
3. Создать Pull Request (PR)
4. Получить аппрувы от команды
5. Влить изменения в `main`

## ✅ Система Approve
- Требуется **N аппрувов** от команды (N = количество участников - 1)
- Автор PR не может аппрувить свои изменения
- После аппрувов можно мержить
