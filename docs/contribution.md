# Процесс работы с репозиторием команды "Чемпионы"

## 📍 Ветки
- **main** — главная ветка, всегда стабильна
- **feature/название-задачи** — ветки для новой функциональности
- **docs/название-задачи** — ветки для работы с документацией

**Примеры названий веток:**
- `feature/create-questionnaire`
- `docs/add-contribution-guide`
- `feature/add-interview-protocol`

## 💬 Коммиты
Формат: `[тип] Описание на русском языке`

**Типы коммитов:**
- `feat:` - новая функциональность
- `fix:` - исправление ошибки
- `docs:` - изменения в документации
- `style:` - правки форматирования
- `content:` - работа над контентом (анкеты, протоколы)

**Примеры:**
- `[feat] Добавлена анкета в content/`
- `[docs] Обновлен процесс код-ревью`
- `[content] Добавлены вопросы для интервью`

## 🔄 Процесс внесения изменений
1. Создать ветку от `main`
2. Выполнить задачу в своей ветке
3. Запушить ветку в репозиторий
4. Создать Pull Request (PR) в `main`
5. Добавить описание, что было сделано
6. Получить аппрувы от команды
7. Влить изменения в `main`

## ✅ Система Approve
- Требуется **4 аппрува** от команды (N = количество участников - 1 = 5 - 1 = 4)
- Автор PR **не может** аппрувить свои изменения
- После получения 4 аппрувов можно мержить PR
- Все обсуждения должны быть разрешены перед мержем

## 🚫 Запрещено
- Прямые пуши в `main` ветку
- Мерж PR без необходимого количества аппрувов
- Создание веток с непонятными названиями
